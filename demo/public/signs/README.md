# Conceptual sign illustrations

These 18 AI-generated WebP illustrations are mapped to Bengali class labels and English names by `signs-manifest.example.json` at the repository root. All entries have `verifiedBdslGesture: false`.

The artwork is conceptual, not verified BdSL instructional material. Illustrated poses are not guaranteed to match the gestures in the model’s training data.

Gallery selection opens guided camera practice with the selected illustration alongside the webcam. Artwork is never automatically submitted to inference. Recognition uses actual camera predictions and requires three consecutive top-label matches at confidence ≥0.65. Changing targets resets progress and invalidates in-flight practice feedback.
